# Нормализация исходников v0.1.0

Этот служебный файл фиксирует запуск одноразовой проверки перед переводом документации и финальным release gate.

Проверка должна:

- исправить освобождение системной блокировки в `Database::close`;
- разрешить только возрастающие WAL sequence с допустимыми пропусками после `DisableWal`;
- применить канонический `rustfmt`;
- выполнить Clippy, тесты, doctests и release-сборку.
