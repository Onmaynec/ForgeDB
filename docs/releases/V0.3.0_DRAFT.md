# ForgeDB v0.3.0 — Full LSM Read Path

Статус: **stacked draft, не выпущено**.

## Реализовано

- MVCC versions и snapshots;
- immutable VersionSet, L0 newest-first, L1+ invariants;
- cursor-based forward range merge;
- block-at-a-time SSTable data reads;
- previous/current WAL recovery и retry-safe flush;
- inventory, recovery plan, quick/deep verify;
- CLI и model/corruption/cursor tests.

Persisted formats остаются V1. MANIFEST пока хранит только L0.

## Range memory contract

Memtables используют frozen vectors. Каждый SSTable source удерживает decoded index и один текущий data block. Heap хранит один current key на source. Полный SSTable не materialize-ится.
