# ForgeDB v0.3.0 — Full LSM Read Path

Статус: **stacked draft, не выпущено**.

## Scope

MVCC snapshots, immutable VersionSet, L0 newest-first, L1+ validation, cursor range scan, block-at-a-time SST reads, WAL recovery, retry-safe flush, inventory, recovery plan, verify и CLI.

Persisted formats остаются V1. MANIFEST хранит L0; L1+ data относится к `v0.4.0`.

## Memory contract

Memtables используют frozen vectors. Каждый SSTable source удерживает decoded index и один current data block. Heap хранит один current key на source. Полный SSTable не materialize-ится.

## Tests в source tree

Multi-block cursor, resident-memory bound, scan через три L0 SSTables, snapshots, model, corruption, deep verify и nondestructive recovery plan.
