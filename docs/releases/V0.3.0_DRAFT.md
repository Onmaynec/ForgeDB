# ForgeDB v0.3.0 — Full LSM Read Path

Статус: **stacked draft, не выпущено**.

Версия строится поверх draft `v0.2.0 — SSTable and Flush`. Merge, tag и GitHub Pre-release запрещены до завершения базовой версии и полного validation gate.

## Основные изменения

- MVCC memtable и snapshot-aware reads;
- immutable `Arc<VersionSet>`, L0 newest-first и L1+ non-overlap invariants;
- cursor-based binary-heap range merge;
- block-at-a-time `SstEntryCursor` с decoded index и одним resident data block;
- previous/current WAL recovery в разные memtables;
- retry-safe flush state machine;
- file inventory, non-destructive recovery plan и quick/deep verify;
- CLI `scan`, `inventory`, `inspect recovery-plan`, `verify --deep`.

## Persisted-format impact

Новые persisted-форматы отсутствуют. IDENTITY, Internal Key, WAL, SSTable, MANIFEST и CURRENT остаются в версии 1. MANIFEST V1 сохраняет L0; физическое заполнение L1+ относится к `v0.4.0`.

## Range scan contract

- forward-only и один snapshot sequence на операцию;
- user keys строго возрастают и не дублируются;
- tombstones и shadowed versions скрыты;
- optional range и limit;
- unread SSTable blocks не загружаются заранее.

Memtables используют `VecEntryCursor`. SSTable source проверяет header/footer/index, затем читает data blocks через `seek + read_exact` по одному. Resident memory включает frozen memtables, decoded index и один data block на активный SSTable source, плюс heap.

## Recovery plan contract

`forgedb inspect recovery-plan <каталог>` выполняет только чтение под process lock. Unknown и user files никогда не включаются в automatic cleanup.

## Реализованные acceptance tests

- multi-block `SstEntryCursor`;
- resident entry count меньше полного SSTable;
- range scan через три L0 SSTables;
- snapshot visibility через overwrite и flush;
- recovery plan не изменяет каталог.

Tests присутствуют в source tree, но их выполнение ещё не подтверждено доступным compiler/CI run.

## Validation gate

```text
cargo fmt --all --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace --all-features
cargo test --workspace --doc
cargo build --workspace --release
```

Требуются Ubuntu stable, Windows stable и Ubuntu Rust 1.89. GitHub Actions run `30878893688` завершил все jobs до первого шага с `steps=null`; локальная Rust toolchain недоступна. Поэтому merge, tag и release не выполняются.

## Ограничения

Нет compaction, физически заполненных L1+, block/table cache, backward iterator, transactions и column-family API. Index выбранного SSTable загружается целиком. Inventory и recovery plan не изменяют файлы автоматически.
