# ForgeDB v0.3.0 — Full LSM Read Path

Дата выпуска: 2026-08-05.

Статус: GitHub Pre-release.

## Goal

Завершить полный snapshot-aware read path поверх mutable/immutable memtables и всех файлов текущего VersionSet, добавить bounded-memory range scan, snapshots, file inventory и verification без изменения persisted-форматов V1.

## Реализовано

- MVCC memtable с несколькими versions одного user key;
- cheap snapshots и active sequence registry;
- `ReadOptions` и snapshot-aware point reads;
- immutable `VersionSet`;
- L0 newest-first source order;
- validated L1+ sorted/non-overlap invariant;
- heap-based merge iterator;
- block-at-a-time SST cursors;
- bounded-memory range scan с bounds и limit;
- file inventory;
- read-only recovery plan;
- quick/deep verify;
- CLI scan/inventory/verify/recovery-plan.

## Доказанные invariants

- snapshot не видит sequence выше собственной границы;
- tombstone скрывает value в соответствии со snapshot;
- L0 читается от новых файлов к старым;
- L1+ ranges не перекрываются;
- range scan выдаёт user keys по возрастанию без duplicate-visible versions;
- scan после нескольких flush соответствует reference model;
- SST cursor удерживает только один data block;
- отсутствующий MANIFEST-owned current/previous WAL блокирует open как corruption;
- recovery plan и verify не изменяют database directory.

## Crash-consistency impact

Persisted installation protocol v0.2 не изменён. Дополнительно open теперь fail-safe проверяет существование всех MANIFEST-owned WAL до replay или append-open, поэтому missing live WAL не может быть замаскирован созданием пустого файла.

## Persisted-format impact

Новая версия persisted format не добавлена.

| Формат | Версия |
|---|---:|
| IDENTITY | 1 |
| Internal Key | 1 |
| WAL | 1 |
| SSTable | 1 |
| MANIFEST | 1 |
| CURRENT | 1 |

## Известные ограничения

- физические L1+ outputs отсутствуют до v0.4.0;
- leveled compaction отсутствует;
- reverse iterator отсутствует;
- transactions отсутствуют;
- flush синхронный;
- write stalls отсутствуют;
- произвольные orphan/unknown files автоматически не удаляются.

`v0.4.0 — Leveled Compaction`: picker, L0→L1, Ln→Ln+1, bounded merge, MVCC/tombstone retention, output splitting, stalls, obsolete file lifetime и manual compact.
